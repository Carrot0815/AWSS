今天學到的六個關鍵字

憑證 Certificate

由 CA 核發，證明網站身分並提供加密用的公鑰，是 HTTPS 的基礎。

Port 連接埠

同一台主機用來區分不同服務的號碼，例如 80 是 HTTP，443 是 HTTPS。

Security Group

Inbound 管進來的流量、Outbound 管出去的流量，是 EC2 的防火牆規則。

CIDR

用「IP / 前綴長度」表示一段位址範圍，例如 192.168.1.0/24。

DNS

把好記的域名翻譯成電腦看得懂的 IP 位址，網際網路的電話簿。

URL

協定 + 主機 + Port + 路徑 + 參數，完整指出網路上的某一個資源。

一次連線背後發生的事

輸入網址→ DNS 查詢 IP→ 連到主機的 Port→ Security Group 檢查 Inbound 規則→ 用憑證建立 HTTPS 加密連線→ 拿到網頁內容
